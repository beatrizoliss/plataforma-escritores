# ETEC Literária

A **ETEC Literária** é uma plataforma digital desenvolvida como Trabalho de Conclusão de Curso (TCC), em 2024, na ETEC Lauro Gomes. O projeto tem como objetivo promover a visibilidade de escritores iniciantes da comunidade escolar, incentivando a produção literária e aproximando escritores e leitores.

A solução foi planejada para oferecer um site e um aplicativo, proporcionando diferentes formas de explorar, compartilhar e acessar conteúdos literários.

## Objetivos do projeto

- Incentivar a escrita e a produção literária no ambiente escolar.
- Ampliar a visibilidade de escritores iniciantes.
- Disponibilizar um espaço para publicação e divulgação de histórias.
- Facilitar o acesso a diferentes gêneros literários.
- Aproximar escritores e leitores por meio de recursos digitais.

## Funcionalidades

### Site

- Página inicial e apresentação do projeto.
- Seção sobre a iniciativa.
- Exploração de histórias e gêneros literários.
- Divulgação e apresentação de escritores.
- Cadastro e login de usuários.
- Área de perfil.
- Publicação de histórias.

### Aplicativo

- Login integrado à conta do site.
- Exploração de gêneros literários.
- Visualização e leitura de histórias.
- Acesso às histórias publicadas pelo usuário.
- Leitura de histórias em PDF.

## Tecnologias utilizadas

As tecnologias documentadas no desenvolvimento incluem:

- **HTML5 e CSS3:** estruturação e estilização das páginas.
- **JavaScript:** recursos e interações da interface.
- **PHP:** processamento das funcionalidades do site.
- **MySQL:** gerenciamento do banco de dados.
- **Bootstrap:** apoio à construção de interfaces responsivas.
- **Java e XML:** tecnologias utilizadas no desenvolvimento do aplicativo Android.

## Organização do projeto

O repositório reúne os arquivos disponibilizados do desenvolvimento, incluindo páginas, recursos visuais, folhas de estilo, scripts e arquivos PHP relacionados à integração com o banco de dados.

## Observações

Este repositório apresenta uma versão dos arquivos do projeto acadêmico desenvolvido em 2024.

A estrutura original do banco de dados não está disponível nesta versão. Por isso, a execução completa das funcionalidades que dependem de persistência de dados exige a configuração de um banco compatível.

A documentação original também contempla o desenvolvimento de um aplicativo Android, mas o código-fonte completo do aplicativo não está incluído nesta versão do repositório.
